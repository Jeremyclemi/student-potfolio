Academic Task Planner

An interactive task manager engineered to track coursework, reading assignments, and project deadlines. All tasks are dynamically updated in the DOM and preserved in browser localStorage.

How the Planner Works (DOM & Storage)

This academic tool is powered exclusively by vanilla JavaScript (ES6) with zero external dependencies:

  • Data Structure: Tasks are maintained in a global array of JavaScript objects. Each object contains an id, title, course, dueDate, priority, and completed status.
  • DOM Manipulation: Whenever a task is added, marked complete, or deleted, the renderTasks() function executes. It clears the container and rebuilds DOM nodes cleanly using document.createElement().
  • Validation: The addTask() function checks user input. If the task title is blank, it shows an alert banner and halts submission.
  • Persistence: The saveTasksToStorage() function serializes the task array into JSON via localStorage.setItem(), allowing tasks to persist across page reloads.
